## Reflection Questions

### 1. What challenges did you face when refactoring your code to use Bootstrap?

the two challenges that I faced when refactoring my code using Bootstrap was first actually getting accustomed towards the language Bootstrap uses and how to include them inline of my code and another challenge was seeing what wasn't needed in the style sheet to mkae sure my design was the same as my previous lab.
### 2. How did using Bootstrap utility classes and components simplify your styling process?

Bootstrap made styling easier by instead of making many classes that go into the style sheet, I can just put the code components for the design inside the class taht i created inline for the component needed.

### 3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?

I might choose to not use Bootstrap and write custom CSS instead in scenarios that involve a more unique design in which CSS is able to go more indepth with it.
